# Iris 的霍格沃茨生日特别任务

生日互动网页与现场寻宝素材。网页从纸质通知书上的二维码开始，逐关要求输入谜题答案，再输入纸质碎片背面的两位魔法印记。

- 网页：<https://outeri.github.io/iris-birthday-quest/>
- 打印版：[print/iris-birthday-printables.pdf](print/iris-birthday-printables.pdf)
- 可自行打印的源文件：[print/printables.html](print/printables.html)

## 现场布置

打印 PDF 时使用 A4、100% 比例、彩色，关闭浏览器页眉页脚。第二页的六张碎片沿外侧虚线剪下，沿中线向背面折，让句子在正面、数字在背面。第三页的价格杯签同样沿中线折，正面留价格，背面留汉字。

1. 入户：已购买的信封、印章与通知书中加入第一页个性化内页，二维码朝向易扫描的位置。
2. 中下卧室：9¾ 标识；车票和 `1002` 登车码小卡放在关闭的行李箱外。音乐盒与碎片⑤放入箱内，贴⑤号封印。
3. 左下卧室：放椅子、3D 分院帽、魔法袍、魔杖和学院徽章。分院帽只是仪式物件，不要求戴在头上。
4. 客厅：活点地图第二道折页放 `OWL POST` 信封，内装海德薇与碎片①。电视柜藏化妆品与手写信。
5. 上中卧室：四杯从左至右固定为可乐、蓝色芬达、橙色芬达、雪碧，碎片②在蓝色杯垫下。
6. 厨房：2、5、8 的价格杯签背面依次为“台”“面”“下”，碎片③贴在靠入口的台面下方干燥处。
7. 上中窄卫生间：在镜旁空白卡上用隐形笔写“门背后”；碎片④在门内侧、把手下方的干燥处。
8. 客厅窗边：金色信封里装飞贼手链与碎片⑥，贴在室内伸手可取的窗框上，不需要探出窗外。

现场开始前，用实际手机扫描二维码，确认页面打开；试照隐形卡；逐处确认不会提前看到礼物或碎片。第③关可作为喝饮料的休息段。

## 页面流程

`docs/` 是 GitHub Pages 的发布目录。网页使用静态 HTML、CSS、JavaScript，无需服务器或账号；进度只保存在当前浏览器的 `localStorage`。页面底部的“重新开始”经确认后清除本机进度。错误答案不会锁关，提示按钮只指出要查看的现场物品。

网页与仓库源码公开可读，日期和关卡校验仅承担游戏流程作用。手绘户型原图没有上传；网页地图只保留房间相对位置。

## 修改二维码

若网页地址改变，先修改 `print/generate_qr.py` 中的 `URL`，再运行 `python print/generate_qr.py` 重新生成 `print/qr.svg`，最后从 `print/printables.html` 重新导出 PDF。纸质二维码必须以最终已上线的网址为准。
